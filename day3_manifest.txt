# Day-3 winners-only inference: the fixed shipping recipe on the HELD-OUT test
# window (2025-02-06 .. 2026-01-01, never touched by training or selection).
#
# RECIPE (fixed 2026-08-11 after the 16-arm wrap-up sweep):
#   quantile head, dropout 0.1, weight_decay 0.001, qw_exp 1.0, 2020+ store,
#   checkpoint best_speed.pth, three seeds.
#
# WHY best_speed.pth AND NOT best_model.pth. Across three seeds the no-dropout
# recipe put best_model.pth at epoch 1 every single time and never beat that
# score in 21 epochs, while dropout 0.1 put it at epoch 7/7/10 -- so the
# apparently better no-dropout twCRPS (0.0695/0.0707) was the epoch-1 artefact
# itself, not a better model. speed_pinball is the stable component (+-6% between
# epochs vs twCRPS's +-14%) and separates the recipes cleanly: 0.2947 +- 0.0017
# with dropout against 0.2995 +- 0.0025 without.
#
# WHY THE DENSE 19-LEVEL GRID (QSUB '-'). CRPS, PIT and interval coverage need
# the full grid; a reduced set is for the shipped product (day 5), not scoring.
#
# Rows 3-6 are diagnostics, not products:
#   row 3  r1_do010 @ best_model.pth  -- epoch 10 vs best_speed's epoch 7, so it
#          measures what the twCRPS selection rule costs. Only meaningful for
#          this arm: on s2 and s3 both checkpoints landed on epoch 7 and are
#          therefore byte-identical weights.
#   rows 4-6  @ best_direction.pth (epoch 27 in all three seeds) -- quantifies
#          the per-head divergence. Direction was still improving when training
#          stopped, so a single checkpoint ships a measurably worse direction
#          field. These carry QSUB=0.5 because quantile_subset touches only the
#          speed/gust levels; the direction channels are written regardless, so
#          the dense grid would be ~11 GB of waste per row.
#
